# Phase 8 final verification boundary

Phase 8 is complete when the retrieval projection, query service, API,
pagination, review workspace, security tests, documentation, and cumulative
quality gates pass together.

The close-out evidence must include repository-marker validation, Java
formatting and tests, `check`, `bootJar`, frontend formatting, ESLint, frontend
tests, production build, Docker Compose configuration validation, whitespace
validation, tenant-isolation coverage, deterministic ordering coverage, and
bounded-response review.
