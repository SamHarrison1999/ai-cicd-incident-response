# Phase 7 final verification

Phase 7 is complete when the five batches are independently verified and the
cumulative baseline remains green.

The final verification evidence must cover repository hygiene, Java formatting,
tests, analysis, coverage, executable JAR creation, frontend formatting and
lint, frontend tests and production build, Docker Compose validation, tenant
isolation, sanitisation, deterministic rules, bounded confidence, abstention,
API contracts, and the human-review workspace.

The final pull request must preserve the distinction between a suspected
diagnosis and a confirmed cause. No autonomous remediation is included.
